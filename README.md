# StitchFlow Manager

Act as a Senior Product Manager, UX Designer, and Full-Stack Engineer.

I want to build a modern garment production management web application.

This is NOT an ERP system.

This application is only for managing our garment production workflow.

The application will integrate with ERPNext later through APIs.

Do not build accounting, inventory, sales, or purchase modules.

Brand:

- Company: Fawri Lifestyle

- Theme: Modern, Minimal

- Primary Color: Lavender (#8B5CF6)

- Mobile-first responsive design

- Large buttons

- Card-based UI

- Very simple for factory workers

Workflow:

1. Sample Creation

2. Material Selection

3. Sample Making

4. Costing

5. Sample Approval

6. Bulk Cutting

7. Bulk Hand Work

8. Bulk Stitching

9. Quality Check

10. Packing

11. Barcode

12. Ready Stock

Create only the UI and project structure first.

Do NOT write backend logic yet.

Generate:

- Project structure

- Navigation

- Dashboard

- Screen routing

- Theme

- Components
